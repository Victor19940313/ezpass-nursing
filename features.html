作者的話

打開一個地方，就能一直念下去。 —— 做這個網站的初衷

我是牙醫系的學生。準備自己的國考時，我一邊念書、一邊把這個網站架起來，九成的時間都花在這裡，課本和共筆幾乎沒翻。考完之後我想到：有國考要考的人這麼多，卡住的地方其實都一樣，這套東西應該也能給其他考生用。護理師版就是這樣來的。

會做這個網站，一開始只是因為我自己需要。準備國考的時間很零碎，題目散在一份一份的試卷裡，同一個觀念的題目要翻好幾個年份才湊得齊；想弄懂一題，光有答案不夠，為什麼對、其他選項為什麼錯，還得自己翻書去找；想做筆記，又要在好幾個工具之間跳來跳去。我想要的其實很簡單：一個不用翻書的網站，打開一個地方，國考需要的都在這裡。沒有這樣的地方，我就自己做一個。

我不是護理背景，題目和詳解我沒辦法替你判斷對錯，但我知道準備國考的人走的是同一條路：時間一樣少、資料一樣散、一樣會在半夜懷疑自己。這個網站把考選部歷年的題目、答案和更正公告全部收齊、分好類，再配上 AI 詳解和筆記工具。如果它能讓你少繞一點路、多一點踏實，那它就值得存在。

網站是我一題一題、一版一版慢慢做出來的。護理師版剛上線，可能還有一些小 bug，題目或答案若跟考選部公告不一樣也請告訴我，我會修。但每一個功能，都是我自己念書時真的需要、真的在用的，所以我很有把握，它足以陪你走到考場。

⚡ 使用前先做這一件事

  1. 到「筆記本」那一頁，照著步驟把 Gemini API key 設定好。
  2. 設好之後，遇到不會的題目按一下，就能直接生成筆記。
  3. 可以的話多設幾把 key。每一把要用不同的 Google 帳號申請，跟親朋好友借幾把來用；我自己用 5 把 就非常夠用。
  4. 順手把 GitHub 圖床 也設定好（一樣照筆記本的入門指引）。現在的 AI 沒辦法自己抓圖，抓到的圖也常常不準，醫學和護理的圖更需要精準；圖床設好之後，編輯筆記或口訣重點時，截圖直接 Ctrl+V 就貼進去，課本、講義、X 光片想貼什麼就貼什麼。

一定要知道的六件事

點開每一項看說明
📝11 年、8,480 題，全部分門別類
  • 105 到 115 年、25 個場次、8,480 題全部收齊，考選部事後更正或一律給分的題目也照公告處理。
  • 每一題都已經分到考點，所以你可以集中火力寫同一類的題。
  • 每題能標記「送分題／一知半解／亂猜一通／不需要懂」，之後只練標記題，一次又一次回來重做，直到它變成送分題。
🎯照考題類型練習：最厲害的功能之一
  • 不是一份一份試卷亂寫，而是挑一個考點，把 11 年來同一個觀念的題目一次寫到滾瓜爛熟。
  • 每個考點做過幾題、錯誤率多少一眼看到，不會今天寫、明天忘。
  • 練習時每一題右上角還有「10 題類似題」，同一個觀念一口氣寫完。
🤖每題 AI 詳解 + 臨床意義
  • Gemini 詳解：為什麼選這個、其他選項為什麼錯，正確率九成以上。
  • 看不慣一大段文字？詳解能一鍵升級成表格，四個選項哪裡對、哪裡錯，一張表看完。
📒AI 幫你做筆記：最厲害的功能之一
  • 設定好 Gemini API 之後，每一題都能做出共筆等級的筆記；再設好 GitHub 圖床，就能把課本圖、X 光片截圖直接貼進筆記。
  • 類似題會自動串進同一篇，越做越完整。
  • 生成不會打斷作答，它在背景處理，你繼續寫下一題；想偷看隨時點開。
💬每題底下都有留言區
  • 卡在同一題的考生可以互相取暖；學霸也可以寫詳解幫助大家，一題一個小教室。
  • 寫得好有回報：留言累積到門檻的讚，或被選為精選詳解，系統自動送你免費天數的序號（規則在「我的獎勵」）。
🧠口訣與重點分享區：大家的口訣一起分享
  • 分科，把自己好記的口訣和重點整理寫上來；想分享就打開「公開」，也可以收藏別人的。
  • 公開章節被付費會員按讚達到門檻，自動送免費天數的序號，越多人愛用、領得越多（規則在「我的獎勵」）。
